Consejo Pro: Formato Tajima DST

El formato Tajima .DST es un formato universal para máquinas de bordar. La mayoría de las máquinas pueden leerlo. Es la opción más segura si no está seguro de qué formato solicitar.

Sobre los Formatos Outline (EMB/PXF)

Para los bordadores que disponen de software de bordado como Wilcom o Pulse, la mejor opción es solicitar un formato outline como .EMB o .PXF. Así podrán modificar el archivo internamente, por ejemplo ajustando la densidad o el tamaño para diferentes telas.

Sobre Melco Condensed (CND)

No recomendamos solicitar diseños en formato CND, ya que muchos recursos (relleno de curvas, compensación, underlay especial, etc.) que utilizamos desaparecen en el formato Melco Condensed. No podemos decirle que no lo use, pero tenga en cuenta estas limitaciones.
