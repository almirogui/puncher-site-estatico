Come faccio un ordine?

Compila il modulo di registrazione, poi vai alla pagina ordini e compila il modulo allegando il logo. Riceverai un messaggio di conferma dell'avvio dell'ordine.

Quanto tempo ci vuole per ricevere il mio design?

Gli ordini vengono di solito consegnati entro 1 giorno o meno dalla ricezione. Ti serve più veloce? Aggiungi la Consegna RUSH (+40%): ordine entro le 14:00 EST, design lo stesso giorno entro le 18:00 EST. Se non rispettiamo la scadenza, la tariffa RUSH non viene addebitata. Dettagli nella nostra pagina prezzi.

Devo pagare la spedizione?

Nessuna spedizione: è un file inviato via email. Ricevi i tuoi design digitalizzati direttamente per email.

Come posso pagare l'ordine?

Il pagamento può avvenire con carta di credito, bonifico o PayPal. Abbiamo una pagina sicura dove completare il pagamento.

Inviate fatture?

Sì, inviamo sempre una fattura per aiutare i clienti a monitorare le spese con noi.

Come inizio a usare i vostri servizi?

Ai nuovi clienti chiediamo di compilare completamente la pagina di registrazione. Appena la registrazione è completata, stiamo già lavorando per te.

I prezzi includono le correzioni?

Sì, facciamo tutte le correzioni necessarie. Costi aggiuntivi solo se il design originale inviato viene modificato.

Come invio il mio logo?

Ci sono 3 modi per inviarci il tuo logo:

  • Via email: Allega un formato comune (gif, jpg, bmp, ecc.) a un'email e inviacelo (Inviaci un messaggio)
  • Dal web: Se il tuo logo è visibile sul web, inviaci semplicemente l'URL via email
  • Tramite il nostro modulo d'ordine: Usa il nostro modulo d'ordine online per caricare il logo direttamente
Potete modificare un file creato da un'altra azienda?

No, possiamo modificare solo file creati da noi.

E se non sono soddisfatto del mio design?

Faccelo sapere! Faremo il necessario per soddisfare le tue aspettative. La nostra politica: la soddisfazione dei clienti. Nessuna restrizione di 30 giorni né garanzie limitate. I nostri design e servizi sono garantiti. Se hai un commento, un dubbio o un reclamo, contattaci e sistemeremo tutto. Semplice così.

Quali formati di file fornite?

Inviamo i file nell'estensione adatta alla tua macchina da ricamo. Lavoriamo con DST, EMB, PXF, PES e molti altri. Consulta la nostra pagina Formati di file per l'elenco completo.

Lavorate con schede macchina?

Non lavoriamo con schede macchina. Inviamo file allegati che puoi trasferire su chiavetta USB o inviare alla macchina con il tuo software di ricamo.

Potete inviare file in formato outline/vettoriale?

Sì, li inviamo in .EMB (formato nativo del software Wilcom) o .PXF (Tajima/Pulse).
